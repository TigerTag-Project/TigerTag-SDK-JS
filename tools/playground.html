TigerTag Init
Blank chipBlank / uninitialized chip. All fields are zero — no data written yet. Ready to be written with any TigerTag-compatible writer.
TigerTag+ · catalogue productTigerTag+ — a TigerTag that knows which catalogue product it is.
The chip carries an official product ID from the TigerTag catalogue (eSun, Polymaker, Rosa3D…) and stays 100 % offline. Anyone can write one.
TigerTag+ Certified adds an ECDSA signature that only a certified manufacturer can issue — this playground can verify it, never write it.
The cloud product ID unlocks rich metadata and enables remote corrections post-deployment — without recalling a single item.
Load a TigerTag+ productEnter a product ID and press Load (or Enter): the whole form is filled, the page switches to Burn and builds the preview. With two readers holding a chip, a twin tag (1 of 2, 2 of 2) is prepared automatically.
Catalogue · …Official TigerTag+ product catalogue (14 000+ products). A copy is bundled with the SDK, so it works without internet; the SDK checks for a newer copy once a day. Update downloads the latest version now (it changes every day).
Tables · …Reference tables (materials, brands, aspects, types, diameters, units, versions). The SDK uses the newest of its bundled copy and the downloaded copy, and checks for updates once a day. Update checks now and downloads only the changed tables.
